# AstroPath 🌙

AstroPath is an interactive space mission planner that visualises planetary motion and simulated interplanetary missions through an animated Solar System.

## Features

- Animated Solar System with orbiting planets
- Mission planning from Earth to Mercury, Venus, Mars, Jupiter and Saturn
- Animated spacecraft trajectories
- Interplanetary distance calculations
- Estimated travel-time calculations
- Mission progress tracking
- Adjustable simulation speed
- Responsive black and red space-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Animation
- Mathematical coordinate calculations

## How It Works

AstroPath uses JavaScript to simulate planetary movement using orbital radius, angular position and simulation speed.

Users can select a destination and launch a simulated mission from Earth. The application calculates a simplified interplanetary distance and estimated travel time, then generates an animated curved spacecraft trajectory between Earth and the selected destination.

During a mission, Earth and the selected destination are temporarily held at their launch positions to provide a clear visual trajectory, while the other planets continue their orbital simulation.

## Disclaimer

AstroPath is an educational visual simulation. Planetary motion, spacecraft trajectories and travel-time estimates are simplified and are not intended for real-world mission planning.
